# Provenance

`OFD-DirectAttention` is an integration research repository. It must not silently absorb moving results from sibling repositories.

Every imported component records:

- source repository;
- exact commit SHA;
- imported semantic contract;
- local compatibility/revalidation status;
- whether the artifact is researcher derivation, assistant synthesis, measured result, or external fact/source.

Assistant-authored prose is organizational material until the proof, code, source, or measurement is independently inspectable.

Historical evidence from the original OFD repository is predecessor evidence only unless explicitly imported with source SHA/path and revalidated under the current DirectAttention semantic contract.
